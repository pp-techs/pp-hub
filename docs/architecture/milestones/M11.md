# M11 — A space is a company, and the disk is honest

✅ done · part of the [delivery milestones index](../milestones.md).

Two halves shipped under this number.

**A space is a company** (the half [SUMMARY.md](../../SUMMARY.md) describes):
`groups` and `shares.kind = 'group'`; space membership grants **no file access at
all**, access comes from grants inherited down the subtree and resolved in one
batched recursive query that also walks through trashed ancestors. Listings,
search, starred, recent, activity and trash narrow to what the caller can reach in
one batch per page, and "Shared with me" is a list of grants. See
[permissions.md](../permissions.md).

**Reclaim, quota, retention and the long tail:**

- **Blob GC** (`internal/gc`, 15-minute sweeps): `ListUnreferencedBlobs` had
  existed since M2 with no caller, so every permanent delete leaked its bytes.
  Only blobs unreferenced for over an hour are considered, and the row is deleted
  **before** the file, so a crash leaves a findable orphan rather than a row
  promising bytes that are gone.
- **Quota is enforced** at upload (413), measured after the bytes land because a
  streamed multipart part does not declare its length. (Superseded by
  `fs.EnsureRoom` in M30.)
- **Editors can edit.** `requireNodeAccess` mapped space roles positionally
  (viewer=1, editor=2, owner=3) against a scale where mutation needs 3, so an
  editor could upload but not rename what it had just uploaded. The mapping now
  lands on the permission scale itself (and is gone entirely in M15); restore
  follows delete down to editor while purge and empty-trash stay owner-only.
- **Trash retention**: `nodes.deleted_by` and `spaces.trash_retention_days`,
  default **0 = never auto-purge**, with an hourly `gc.TrashWorker` inert until a
  space opts in; the UI shows who deleted an item and its countdown.
- **Long tail**: copy by blob reference (duplicating a 2 GB video costs one row;
  a copy into the original's own subtree is rejected), search `owner`/`modified`
  filters, member detail from one query, and a create-space form taking slug /
  description / default role / quota.
- **Web component testing** arrived here (`@testing-library/react` + `happy-dom`
  behind a per-file `@vitest-environment` pragma).
