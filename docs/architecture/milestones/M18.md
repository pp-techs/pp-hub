# M18 — The shell is the shadcn dashboard shell

✅ done · part of the [delivery milestones index](../milestones.md).

- `drive.tsx` is `SidebarProvider` → `app-sidebar.tsx` (`variant="inset"`,
  `collapsible="offcanvas"`) → `SidebarInset`: collapse on ⌘/Ctrl+B, remembered
  in a `sidebar_state` cookie, sheet below `md`. `drive-header.tsx`,
  `drive-toolbar.tsx` (dead), `quick-access.tsx` and `rail-item.tsx` are gone.
- **One header.** `site-header.tsx` renders the trigger, a pathname-derived
  breadcrumb, the ⌘K button and a portal slot that surfaces fill through
  `HeaderActions` instead of stacking their own band. The slot is a portal and
  not `ui-store` state deliberately: a `ReactNode` is not UI state, and this
  avoids effects writing on render and stale nodes after unmount.
- `surface.tsx` owns page rhythm (`@container/main`, `px-4 lg:px-6`,
  `py-4 md:py-6`); the folder listing opts out on purpose — rows reach the edges
  and scroll under a sticky header, and the container query is what lets the
  details panel narrow the column without the route knowing.
- Two load-bearing invariants: `SidebarInset` must stay a _direct sibling_ of the
  sidebar (its margin and rounding are `peer-data-[variant=inset]:…`, and a peer
  selector only matches a preceding sibling), and the shell must pin
  `h-svh overflow-hidden` because `SidebarProvider` is only `min-h-svh`.
