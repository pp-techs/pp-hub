# M7 — Search & command palette

✅ done · part of the [delivery milestones index](../milestones.md).

- `pg_trgm` with a GIN trigram index on `nodes.name` (partial on
  `deleted_at IS NULL`) and `space_members_by_user`.
- `GET /api/v1/search?q=&space=&kind=&limit=` returns a node DTO plus
  `space_name` and `parent_name`:
  - scope is the caller's membership, joined **in** the query so an
    unseeable row is never fetched; direct shares deliberately do not widen it;
  - `q` under 2 runes answers `200 []`, not an error — the palette calls it on
    every keystroke; `limit` defaults to 20 and clamps at 50;
  - ranking promotes a prefix match over a mid-string one, then falls back to
    trigram `similarity()`. `parseSearchQuery` holds the validation and is
    unit-tested without a database.
- Web: `command-palette.tsx` (⌘K, mounted by the shell), debounced input,
  Files/Folders/All chips. The rail field is a **different tool** — it filters
  the open folder locally and instantly, and says so.
