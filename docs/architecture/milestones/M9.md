# M9 — Stars, activity, recent & home

✅ done · part of the [delivery milestones index](../milestones.md).

- `node_stars` (composite PK, so starring is idempotent; per-user, because two
  people can disagree about whether a file matters) and `activity_events`
  (`node_id ON DELETE SET NULL` and its own `node_name`, so purging a file does
  not erase the record that it existed).
- `activity.Service` records uploaded / created / renamed / moved / trashed /
  restored / purged / shared / unshared / reverted — **best-effort by design**:
  failing a user's upload because an audit line could not be written trades a
  real outcome for a cosmetic one.
- `GET /api/v1/activity|recent|starred|usage`, `POST|DELETE /nodes/{id}/star`
  (a star needs only read access — it is a private note about the node).
  `used_bytes` is maintained by `fs.RecountUsage` after size-changing
  mutations (superseded by `SumSpaceUsage` in M30).
- Web: cross-space Home/Recent/Starred, activity feed, storage breakdown —
  **superseded by M16**, which scoped all three to one space.
