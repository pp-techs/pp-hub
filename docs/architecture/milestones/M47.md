# M47 — WebDAV access

✅ done · part of the [delivery milestones index](../milestones.md). The design
in force is [webdav.md](../webdav.md). Builds on [M41](M41.md)'s personal
tokens and in-process agent router.

- **The decision.** A coding agent on a laptop (Claude Code, Cursor, Codex)
  wants local tools — pandoc, python, a script — over the company's files.
  WebDAV, not a pull/push CLI or a two-way sync app: nothing is copied, so
  there is no change feed to build and no revoked grant to chase down a local
  copy. rclone's VFS cache is the recommended client for agents.
- **One set of rules.** Every write is an `/api/v1` call answered in process by
  the agent router as the token's owner (`innerRequest` in `agent.go`, now
  shared with `agentAPI.Do`), so capabilities, team-folder rules, editor locks,
  quota, activity and audit are the web client's. Reads list through the same
  service calls as the listings. `golang.org/x/net/webdav` answers `PROPFIND`,
  `PROPPATCH`, `LOCK` and `UNLOCK` over adapters; `GET`, `HEAD`, `PUT`,
  `DELETE`, `MKCOL`, `COPY` and `MOVE` are pp-hub's own
  (`internal/httpapi/dav*.go`).
- **Its own token.** Migration `0025`: `agent_tokens.purpose` (`'mcp'` |
  `'dav'`). `POST /users/me/agent-tokens` takes `purpose`; the lookup filters on
  it, so a WebDAV token is refused at `/mcp/` and the reverse. Audit client id
  `dav:<id>`. Minted in Settings › Security › Mount as a drive; `GET
/users/me` carries `webdav_url` while the switch is on.
- **Endpoint.** `/dav` sits outside `/api/v1`, Basic (password = token) or
  Bearer, no cookie, no `sameOrigin`. Per person 6000/min (burst 1200), refusals
  per address 60/min (burst 20). `webdav_enabled` (`system_config`, default
  **off**, Admin › Settings › WebDAV) answers 404 while off.
- **Saves keep history.** A write over a file is a new version; one that raced
  another writer since this token's last read lands as a conflicted copy (201).
  Safe-save patterns (temp + `MOVE`, scratch rename, delete + rewrite) become a
  new version of the original node. Editor scratch files never become nodes.
  `DELETE` trashes. Locks are in memory, per person and node, not `file_locks`.
- **Proxy.** `apps/web/nginx.conf` proxies `/dav` with no body cap, no
  buffering and 3600 s timeouts; the Vite dev proxy forwards it.

## Not built

Delta sync, offline work, files-on-demand placeholders, sharing over WebDAV, a
change feed. Finder, Explorer, desktop Word and `rclone nfsmount`/`mount` are
not yet exercised; verification is real rclone commands against the production
router plus `dav_db_test.go`.
