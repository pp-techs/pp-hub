# M39 — Block documents

✅ done · part of the [delivery milestones index](../milestones.md).

- What asked for it: not a P1 gap but a product request — a Lark/Notion-style
  block editor beside the office formats, for specs, runbooks and notes. The
  full design, the alternatives rejected and the spike are in
  [block-documents.md](../block-documents.md).
- **Decision: a document is a plain `.md` file node.** Versions, shares, trash,
  previews and quota all apply unchanged. `internal/fs/markdown.go` registers
  `.md` as `text/markdown; charset=utf-8` rather than leaving the type to the
  host's `mime.types`, and `0014_markdown_mime.sql` backfills it onto `.md`
  versions stored as `application/octet-stream` or `text/x-markdown`, so files
  uploaded before M39 open too. **New → Document** takes `kind=markdown` on
  `POST /spaces/{id}/documents`.
- **Decision: realtime co-editing in the Go binary, not a sidecar.**
  `internal/collab` runs reearth/ygo's Hocuspocus-speaking `websocket.Server`,
  vendored under `apps/server/third_party/ygo` with three patches
  (`PATCHES.md`): `ConnectionOrigin` so a version is attributed to its writer,
  SyncStatus acknowledgements because `HocuspocusProvider` counts unsynced
  changes until they arrive, and a server Ping because the provider reconnects
  after 30 s without a message. Rooms are `<nodeId>.<epoch>`, the epoch
  refusing a client that holds a previous generation of the regenerated Y.Doc.
  A room writes back after 30 s quiet (5 min at most) and on shutdown
  (`srv.RegisterOnShutdown`), only when the markdown differs; stays resident 2
  min after its last peer; and holds a `collab:`-prefixed `file_locks` row
  meanwhile, cleared at startup if a previous process left one. Every 60 s
  each peer's session and capabilities are re-resolved and a changed peer's
  socket is closed. One instance hosts every room.
- **Decision: markdown ↔ Y.Doc in Go (`internal/mdoc`), held to slash-editor
  by golden fixtures.** `bun apps/web/scripts/mdoc-fixtures.ts` writes 121
  fixtures and `schema.json` from slash-editor itself, using the same
  `createMdocKit()` (`apps/web/src/lib/collab/mdoc-kit.ts`) the editor mounts;
  Go must reproduce them, and `apps/web/tests/mdoc-go-updates.test.ts` requires
  slash-editor to read Go's seeds back. Markdown outside the v1 block set opens
  read-only as **lossy**; frontmatter is kept outside the editor.
- **Decision: attachments belong to the document.** `0013_block_documents.sql`
  adds `node_attachments` (reference-counted by trigger, cascading with the
  document, copied with it) and `uploads.attach_to`/`attachment_hash` with the
  `uploads_one_target` check. The markdown stores `attachment:<hash>`.
- Routes: `GET /api/v1/nodes/{id}/collab` (`{room, can_write, lossy}`;
  `CapDownload`; 413 over 16 MiB), `GET /api/v1/collab/{room}` (the socket,
  behind `socketOrigin`), `GET /api/v1/nodes/{id}/attachments/{hash}`
  (`CapDownload`), tus uploads with `attach_to` (`CapEdit`). Restoring a
  version while a room is open reseeds it (`collab.Service.Reseed`).
- Web: `/edit/$nodeId` serves both editors; `components/doc-editor/`,
  `components/nodes/` (image, file, mermaid node views) and `lib/collab/`
  (room lifecycle, attachments, presence). The provider is closed on
  `pagehide` and reopened on a back/forward-cache `pageshow`: Chrome kept a
  page with an open socket in that cache, leaving a navigated-away tab joined
  — found in the browser smoke test.
- Deployment: an nginx `/api/v1/collab/` WebSocket location, `wss:`/`ws:` in
  CSP `connect-src`, `pphub_collab_*` metrics, and the Dockerfile copying
  `third_party/`. See [deployment.md](../../deployment.md#block-document-collaboration).
- Tests: `internal/mdoc` against the fixtures and schema; the Go→JS vitest;
  `internal/httpapi/collab_db_test.go` (capability matrix, read-only edits
  dropped, recheck closing only the affected peers, write-back as the writer,
  shutdown flush, the lock, reseed on restore, stale locks released) and
  `attachments_db_test.go` (access follows the document, reference counting);
  `TestCollabSocketRefusesForeignOrigins`. A browser smoke test had two users
  in separate contexts co-edit one document live (presence avatars, remote
  caret), with versions written per author, the downloaded `.md` GFM with a
  `> [!TIP]` callout and `![](attachment:<hash>)`, an uploaded image rendered
  through the attachments endpoint, and a lossy upload opened read-only behind
  the **Edit** warning.
