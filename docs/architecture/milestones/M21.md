# M21 — Access re-resolved, and the controls that were missing

✅ done · part of the [delivery milestones index](../milestones.md).

- `0003_security_events.sql`. No new product surface except an admin-readable
  log; one route group (`/wopi/`) removed from nginx.
- **The through-line is M20's**: find everything that still decided access once.
  A public link checked its token and expiry and nothing else, so revoking the
  grant behind it left every link alive anonymously — `resolveLinkNode` now
  re-resolves the creator's `CapShare` and answers 404. A WOPI token carried the
  rank decided when the editor opened and `GetFile` accepted rank 1, which made
  an editor session the way around a no-download grant; it now requires rank ≥ 2,
  and `handleEditSession` requires `CapDownload` and mints rank 2. And the
  caller's own IP was the caller's choice, which made every limit keyed on it
  decorative.
- **The view/download split is a rule, not a label**: `/s/{token}/content` and
  `/preview?kind=text` (a verbatim 4 KiB prefix — the whole document for a note or
  a key) both take download; `kind=thumbnail` stays on view, because a 256px
  rasterization is genuinely derived. The accepted cost is in
  [permissions.md](../permissions.md).
- **Two controls did not exist.** `Server.sameOrigin` wraps `/api/v1` and
  `/auth/logout`, compares `Origin` (or the _origin_ of `Referer`, never its path)
  against `PP_EXTERNAL_URL`, fails closed when that will not parse, and runs
  before `authenticated`; `/wopi/*` and `/auth/callback` are exempt. Per-IP token
  buckets: `/auth/*` 30/min burst 10, `/s/{token}` 60/min burst 20, `/api/v1`
  1200/min burst 200 — in-process, so N replicas allow N×, as
  [deployment.md](../../deployment.md) says. Upload bodies bounded by
  `PP_MAX_UPLOAD_BYTES` (5G) through `http.MaxBytesReader`, since
  `ParseMultipartForm`'s argument was a spill threshold, never a limit; since M30
  that guards only WOPI `PutFile` and the avatar.
- **The audit trail is a second table**, because an auth event has no space and a
  failed sign-in may have no account: `security_events` + `internal/audit` record
  login, login_failed, logout, session_revoked(s), identity_adopted,
  admin_granted/revoked, account_suspended/unsuspended, grant_created/revoked,
  share_revoked and member_added/removed with client IP, user agent and request id.
- **The first admin is a configuration value**: `PP_BOOTSTRAP_ADMIN_EMAIL`
  promotes that address on every sign-in — idempotent, and therefore the recovery
  path for an install whose last admin was demoted — gated on a **verified**
  email claim.
- **Provenance and edge**: `ClientIPFromXFF(PP_TRUSTED_PROXIES…)` replaces chi's
  deprecated `RealIP`, which believed `True-Client-IP`/`X-Real-IP`/
  `X-Forwarded-For` from anybody; nginx became an envsubst template carrying CSP,
  HSTS, `X-Frame-Options: DENY`, `Referrer-Policy` and `nosniff`, with token
  redaction in its log; `/wopi/` is no longer proxied; compose splits one flat
  network into `edge`/`data`/`office`; `apps/server/.dockerignore` was added
  because these images build with `context: ../../apps/server`.
- Structural guards: `TestEveryAPIMutationChecksOrigin` and
  `TestWopiIsExemptFromOriginChecks` (which fails if the WOPI group ever _is_
  wrapped, because that would break every office save), plus `csrf_test.go`,
  `ratelimit_test.go` and the two-sided redaction test.
- **Also closed by the same pass** — the individual sweep findings, kept in
  [production-readiness.md](../production-readiness.md) §8: `DeleteShare` is
  scoped by node, so sharing one node no longer lets a caller revoke a share on
  another; `spaces.SetAdmin` requires membership, or it seated an admin the People
  page does not list; `application/octet-stream` left `isOfficeMime`, where it had
  made the allowlist mean "any file with an unfamiliar extension"; WOPI `GetFile`
  and the anonymous share path gained `nosniff` and an explicit
  `Content-Disposition`; and the access log redacts share tokens and
  `access_token=` without ever rewriting the request — an earlier version that
  swapped `r.URL` too made chi route the redacted path, so every share link
  answered 404 with a log that looked perfect.
