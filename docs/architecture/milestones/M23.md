# M23 — Mail transport, invitations only

✅ done · part of the [delivery milestones index](../milestones.md).

_Superseded by M33, reused by M31/M35_.

- `internal/mail`, a small `net/smtp` wrapper (dial, STARTTLS or implicit TLS,
  optional PLAIN auth, header injection rejected on any `\r`/`\n` in recipient or
  subject). `config.validateSMTP` fails startup on a half-configured transport
  rather than at the first send; `Host == ""` is a supported, logged state.
- `handleCreateInvitation` sent synchronously under a 15s timeout after the
  invitation row was committed; a failure was logged and the response still
  carried the URL, so the admin's fallback was the old behaviour rather than a
  new failure mode. Verified against a MailHog catcher, not only unit tests.
- The space invitation was the **only** message, so M33 deleted the package with
  it. **M31 and M35 brought mail back** — share-notification email and security
  alerts — configured in Admin › Settings rather than only by environment, so
  "there is no mailer" is no longer true.
