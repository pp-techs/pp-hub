# M34 — One settings dialog

✅ done · part of the [delivery milestones index](../milestones.md).

- M16 gave settings an address and, with it, two of everything: three account
  routes behind a tab strip, three space routes behind a second copy, entered
  from two different rail menus, each taking over the content column. There is
  now one dialog opened by `#settings/general|profile|security|space|members|groups|danger`
  on whatever page the reader is on — so flipping a theme no longer navigates
  away from the folder being worked in.
- **The hash is what opens it, and the flow is one-way**:
  `settings-hash-bridge.tsx` is the only caller of `SettingsModal.show/hide` and
  reads the hash; every exit inside the dialog is a navigation that strips the
  fragment. Opening pushes (Back closes), switching pane replaces. The invariant
  M16 paid for is intact — a pane survives reload, is sendable and answers Back.
  The bridge is mounted in the drive shell, so the fragment stays inert on
  `/login` and `/s/{token}`.
- Two non-incidental details: the nav is plain markup rather than the `Sidebar`
  primitive, because `ModalContainer` sits outside the drive shell's
  `SidebarProvider` and a second provider would register a second ⌘B handler; and
  **unsaved edits block Escape and backdrop clicks** (the close button and a pane
  switch ask first) — a page took a deliberate navigation to leave, a dialog does
  not, so the guard is new rather than inherited.
- Space panes are admin-only by **filtering the pane list**, with a deep link to a
  hidden pane replaced by the default and the filter waiting for the spaces query
  to settle, since "not loaded yet" is not "not an admin".
- Membership picked up a real change: `?group=` meant both the table's filter and
  the drawer's subject, so Members and Groups became separate panes and the filter
  became plain component state. Ten route files and `settings-tabs.tsx` were
  deleted rather than redirected; a stale `/drive/account/profile` bookmark lands
  on "Space not found" inside the shell, which is acceptable for an internal tool.
