# M5 — Previews & jobs

✅ done · part of the [delivery milestones index](../milestones.md).

- `jobs` (kind/payload/status/attempts/backoff) and `previews`
  (version + kind → blob hash). The worker claims with `FOR UPDATE SKIP LOCKED`,
  filtered to the kinds it registered renderers for.
- Images, PDFs and video render to a 256px PNG; text takes the first 4KB.
  `fs.SetVersionHook` enqueues a job after every commit. See
  [preview-pipeline.md](../preview-pipeline.md).
- `GET /nodes/{id}/preview?kind=` serves the preview;
  `GET /nodes/{id}/content` streams the original (allowlisted MIME, Range-capable)
  so PDFs and video render at full size.
- Delivered after M5: real PDF rasterisation (pdftoppm) and video frames
  (ffmpeg) in the optional `cmd/worker` container. Office thumbnails via the
  OnlyOffice conversion API remain deferred.
- The expired-lock sweep runs every 5m in-process.
