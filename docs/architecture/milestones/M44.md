# M44 — Extension host

✅ done · part of the [delivery milestones index](../milestones.md).
The design, its rejected alternatives and the edge cases are in
[extensions.md](../extensions.md); this file records what shipped.

- **What asked for it.** A kanban board for project managers, and the wish
  that pp-hub grow by small apps rather than by edits to its core, the way
  Nextcloud does.
- **Shape.** Compile-time extensions behind a public SDK, switched on per
  instance and per space; no sandbox, no runtime install.

## What shipped

- **`apps/server/extsdk`** — the contract: `Ext`, `Manifest`, `NodeKind`
  (`OnCreate`, `OnCopy`, `ValidSubject`) and `Host` (`Router`, `DB`, `Guard`,
  `Allowed`, `Caps`, `SearchPeople`, `Users`, `Resolve`, `Realtime`,
  `Comments`, `Notify`). It imports nothing from `internal/`;
  `TestExtImportsOnlySDK` walks the imports of the SDK and of every file under
  `apps/server/ext/` and fails on any path through `internal/`.
- **`internal/exthost`** — validates manifests (id `^[a-z][a-z0-9_]{1,30}$`, kinds
  `<id>.<name>`), applies each extension's migrations (schema `ext_<id>`,
  `ext_migrations` track, `search_path` set only while a migration runs), mounts
  its routes at `/api/v1/ext/{id}` **inside the authenticated group** (so
  `TestEveryAPIRouteIsAuthenticated` and `TestEveryAPIMutationChecksOrigin`
  cover them — the route walks build a server with the kanban routes
  registered), gates them on the instance switch, and resolves every node
  decision through `share.EffectiveCapsForNode`. `Guard` and `Allowed` are one
  decision (`authorize`): live node of the kind, extension on for its space,
  capability held. An in-process SSE broker (`Realtime`) serves a stream and
  re-asks `Allowed` and the session every minute (`Config.StreamRecheck`).
- **Core.** Migrations `0022` (enum value `ext`, alone because Postgres will not
  use a value in the transaction that adds it) and `0023`: `nodes.ext_kind` with
  `nodes_ext_kind_ck`, `ext_state`, `ext_migrations`, the widened
  `notifications_kind_check`. `fs.CreateExt` and `copyExt` write an extension
  node and run its hook in the same transaction; `fs.Tree` skips extension
  nodes in a zip; the listing, search, recent, starred and trash DTOs carry
  `ext_kind`; a link share to an extension node answers 422 and a shared
  folder's listing leaves it out.
- **API.** `GET /extensions[?space_id=]`, `PATCH /admin/extensions/{id}`,
  `PUT /spaces/{id}/extensions/{id}`, `POST /spaces/{id}/ext-nodes`.
- **Web.** `apps/web/src/ext` registry (`types.ts`, `registry.ts`), editor
  dispatch in `/edit/$nodeId`, New-menu entries, icons, node actions without
  byte operations, Admin › Apps and Settings › Apps.

## Departures from the design

- **No `Activity` on the host.** Nothing used it; the node's own creation is
  recorded by the core.
- **`DB` is the pool, not a schema-scoped connection.** `search_path` is
  session state and a pool hands out sessions; extension code qualifies its
  tables (`ext_kanban.cards`) instead.
- **Space switch semantics.** A space row can only switch an instance-enabled
  extension off; switching back on deletes the row, so the space follows the
  instance again.

## Deliberately not built

Share links to extension nodes, MCP tools from extensions, per-extension
translation catalogs, a published SDK with a semver promise, installing without
a rebuild.
