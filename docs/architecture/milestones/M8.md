# M8 — Public browsing, preview tabs, editor chrome

✅ done · part of the [delivery milestones index](../milestones.md).

- **Anonymous share browsing**: `GET /s/{token}/children|content|node-download|download-all`.
  Every node id an anonymous caller supplies is walked back up to the share
  root, and a node outside the share answers **404, not 403** — confirming it
  exists is itself more than the visitor should learn. Owner names are stripped.
- **Folder download is a streamed zip** (share links and
  `GET /nodes/{id}/download` on a folder), one file handle at a time; a failed
  entry is skipped so the archive never looks whole while truncated.
- **Bug**: `Content-Disposition` was built with `strconv.Quote`, which adds its
  own quotes, so browsers saved files with quotes in the name. Now
  `mime.FormatMediaType`, which also handles non-ASCII.
- `GET /nodes/{id}` added — the editor route knows only an id; the breadcrumb
  workaround for the same absence was retired in M18. The preview modal got
  Details/Versions tabs and a pager; the office editor gained pp-hub chrome
  (back, name, version, share/versions/download) while ribbon, save indicator
  and presence stay OnlyOffice's.
