# M31 — Document creation, and share notifications

✅ done · part of the [delivery milestones index](../milestones.md).

- `POST /api/v1/spaces/{spaceID}/documents` writes a blank document, spreadsheet
  or presentation from `internal/office/templates.go` into the write target M19
  resolves, in the caller's locale, then opens the editor on it — before this,
  every document had to be created somewhere else and uploaded, which left a real
  co-editing stack working as a viewer with write access.
- Same delivery: **share notification email**. `internal/notify.Shared` enqueues
  one message per recipient as a job, honoring a per-user opt-out
  (`users.settings.email_on_share`, default on) and rendering in the recipient's
  locale. A share that already succeeded never fails because mail did — failures
  are logged.
- This is the notification half of P0 §2, so M29 is comments plus in-app
  notifications, not "no mailer at all"; M23's transport is back (see the M23
  entry) and now configured in Admin › Settings (M35).
