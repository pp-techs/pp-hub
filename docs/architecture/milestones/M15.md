# M15 — Owner-anchored permissions

✅ done · part of the [delivery milestones index](../milestones.md).

- Schema consolidated into a single baseline, `0001_init.sql`, replacing fifteen
  incremental files — acceptable exactly once, pre-production.
- **Access is two mechanisms and nothing else**: ownership (`nodes.created_by`,
  inherited down the subtree and resolved in the same recursive query as the
  grants, so it is not a row anyone can revoke) and grants. Everything created is
  private until it is shared. See [permissions.md](../permissions.md).
- **Admin stopped meaning access**: the role scale is gone (no
  `space_members.role`, no `spaces.default_role`, no `roleRank`, no
  `RequireRole`). Admin is membership of the space's automatic `Admin` group, it
  gates space administration through `spaces.RequireAdmin`, and it gates **no
  file at all**.
- **Grants became level + flags**: `level` (`view` | `edit`) plus independent
  `can_download` and `can_share`, with CHECKs that an editor can always download
  and a link is always view-only and never re-shareable, and `Caps.Covers`
  refusing escalation on create and upsert (403).
- **Departure has an answer**: the space's `Archive` folder holds one server-made
  grant for `Admin`; `RemoveMember` revokes the leaver's grants in both
  directions, climbs nested `created_by` to the nearest ancestor owner, moves
  their roots under the Archive, then drops their group rows, and losing the last
  admin is refused (409).
- Personal folders retired — a member's top level is `ListEntryPoints`, the
  topmost nodes they own or were granted. Node DTOs carry `caps`. (Its ancestor
  walk was fixed after the fact: it never terminated under `UNION ALL` and hung
  `/children` and `/tree`; it now climbs `parent_id` under `UNION`, pinned by
  `TestNestedOwnedNodesAreNotSeparateEntryPoints`.)
- The invariants are SQL, so they are asserted against a real Postgres
  (`internal/spaces/permissions_db_test.go`, skipped without
  `PP_TEST_DATABASE_URL`).
