Cmd+S (Ctrl+S) now saves the open file. In a block document or an office document it asks the editor to write what it holds as a version right away, instead of at the next quiet period or periodic save, and says whether it saved or had nothing to save. It works while the cursor is in the page; inside OnlyOffice's own frame the key stays with OnlyOffice.

Administrators get a new **Open files** page in the admin console. It lists every file open in an editor right now, with when it was opened, last active and last saved, and can ask one file or all of them to save. Use it before a redeploy to see what a restart would interrupt and to save it first.
